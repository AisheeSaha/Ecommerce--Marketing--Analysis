# E-commerce Sales & Marketing Analysis

## 📌 Project Overview

This project analyzes e-commerce sales and digital marketing data to uncover revenue trends, evaluate regional and product category performance, and assess advertising effectiveness.

## 📊 Dashboard Preview

![image Alt]()

## 🎯 Business Objectives

- Analyze revenue trends and overall sales performance.
- Identify high-performing product categories and regions.
- Evaluate advertising effectiveness using clicks, impressions, CTR, and CPC.
- Examine conversion rates and the relationship between advertising spend and revenue.
- Generate actionable insights to support marketing optimization and business growth.

## 📈 Dashboard Features

- Key Performance Indicators (KPIs): Revenue, Units Sold, Advertising Spend, Clicks, Impressions, and Conversion Rate.
- Sales Performance Analysis: Explore revenue trends across transaction dates and product categories.
- Regional Analysis: Compare sales performance across different regions.
- Marketing Performance Analysis: Evaluate advertising clicks, impressions, CTR, and CPC.
- Advertising Effectiveness: Examine conversion rates and advertising spend alongside revenue.
- Interactive Filters: Explore sales and marketing metrics by category, region, and transaction period, where supported by the dashboard.

## 🛠️ Tools & Technologies

- Python (Pandas): Data cleaning, preprocessing, and data transformation.
- SQL Server: Data querying, aggregation, and business analysis.
- DAX: Measures and calculated metrics for sales and marketing performance.
- Power BI: Interactive dashboards, KPI tracking, and data visualization.


## 🔍 How to Explore This Project

1. Clone or download this repository.
2. Review the Python-pandas-jupyter notebooks to understand the data cleaning and preprocessing process.
3. Open the SQL scripts in SQL Server Management Studio (SSMS).
4. Explore the business questions and SQL queries used to analyze sales and marketing performance.
5. Open the Power BI file in Power BI Desktop.
6. Interact with the dashboard to explore revenue trends, regional performance, and advertising metrics.
